# LangChain4j 1.22.0 → 1.23.0, Quarkus 3.40.1 → 3.40.1.1, MCP server 2.0.3 → 2.0.4, logback 1.6.5 → 1.6.6

**Scope:** both chatbot tracks (`workshop/` and `solutions/`), snippets, READMEs, `CLAUDE.md` · audio module out of scope
**Java release:** 25 (`//JAVA 25+`, `maven.compiler.release` 25) · built and run here on Temurin 26
**Verdict:** drop-in bumps on both tracks, no code change required. Nothing the workshop calls was removed or deprecated, the tool error handler defaults announced in 1.21 have still not changed, and the documentation pages the exercises follow describe the same APIs. Two behaviour changes work in the workshop's favour (HTTP/1.1 on plain `http://`, in-stream provider errors now fail the stream).

### Considered, not applied

- **Decision agent for the critic** (`VisionCritic` in modules 7 and 8): `agents.md` now shows a `StyleScorer` loop rewritten as a decision agent returning a `Scale`. It is `@Experimental`, needs a `DecisionModel` (OpenAI decision models rely on token probabilities), and nobody has checked whether AI Endpoints' vision models return them. Not a fit for the workshop until probed, and it would change the exercise rather than modernise it.
- **`maven-compiler-plugin` 3.16.0** is published, but the Quarkus 3.40.1.1 platform generates 3.15.0; the module follows the platform's value.
